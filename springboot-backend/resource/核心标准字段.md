# 核心标准字段

本文档用于后续专利数据治理、知识库建设、检索召回、专利画像、智能推荐和增强分析。

## 一、基础检索必需字段

这些字段按两份设计文档中的“专利主数据字段”“检索结果最小字段集”和“数据内容设计”收敛，只保留支撑专利识别、列表展示、语义检索、知识库切分和基础过滤的最小字段。权属主体、地区、价值评分、引用关系和 DWPI 信息不放在基础检索必需字段中。

| 字段名 | Excel来源列 | 主要用途 |
| --- | --- | --- |
| `申请号` | 第9列：`申请号` | 专利主键候选字段，可映射为系统内 `patentId` |
| `公开（公告）号` | 第7列：`公开（公告）号` | 专利公开或公告编号，用于展示、详情查询和外部检索 |
| `标题 (中文)` | 第2列：`标题 (中文)` | 列表展示主标题，参与关键词检索和语义检索 |
| `摘要 (中文)` | 第4列：`摘要 (中文)` | 核心检索文本，参与知识库切分、Embedding 和画像分析 |
| `首项权利要求` | 第17列：`首项权利要求` | 权利要求文本，用于知识库切分和语义检索 |
| `独立权利要求` | 第19列：`独立权利要求` | 关键权利要求文本，用于技术保护点识别 |
| `发明人` | 第84列：`发明人` | 发明人或团队成员信息，用于科研团队展示 |
| `申请日` | 第10列：`申请日` | 专利申请时间，用于时间筛选和生命周期判断 |
| `公开（公告）日` | 第8列：`公开（公告）日` | 公开时间，用于排序、筛选和公开年份派生 |
| `当前法律状态` | 第148列：`当前法律状态` | 当前法律状态展示和风险判断 |
| `IPC` | 第32列：`IPC` | 专利分类号，用于技术领域识别和检索过滤 |

## 三、智能推荐与价值评估重点字段

这些字段不仅应保留，而且应作为推荐排序、专利价值判断、结果解释和 SWOT 分析的重点字段使用。

| 字段名 | Excel来源列 | 重要性说明 |
| --- | --- | --- |
| `合享价值度` | 第206列：`合享价值度` | 专利综合价值评分，可用于高价值专利筛选、推荐排序和后台看板 |
| `技术稳定性` | 第207列：`技术稳定性` | 反映技术可靠性和成熟程度，可用于落地风险判断和 SWOT 分析 |
| `技术先进性` | 第208列：`技术先进性` | 反映创新程度和技术壁垒，可用于推荐理由、竞争力分析和替代风险判断 |
| `保护范围` | 第209列：`保护范围` | 反映权利要求覆盖范围，可用于专利价值、壁垒和合作风险评估 |
| `引证次数` | 第110列：`引证次数` | 反映被后续技术引用情况，可辅助判断基础性和影响力 |
| `被引证次数` | 第111列：`被引证次数` | 反映专利影响力，可用于价值排序和技术热度分析 |

| `扩展同族个数` | 第133列：`扩展同族个数` | 补充同族规模判断，用于专利族价值分析 |
| `DocDB同族个数` | 第134列：`DocDB同族个数` | 补充同族规模判断，用于外部专利族体系对齐 |
| `同族国家/地区` | 第135列：`同族国家/地区` | 反映地域布局，可用于市场覆盖分析 |
| `最早优先权日` | 第139列：`最早优先权日` | 判断技术起始时间和专利生命周期 |
| `专利有效性` | 第147列：`专利有效性` | 有效、失效等状态过滤，用于推荐和风险判断 |

## 七、推荐落库分层

建议后续处理时按以下层次落库或建索引：

1. **专利主数据层**：来自第2列 `标题 (中文)`、第4列 `摘要 (中文)`、第6列 `申请人`、第7列 `公开（公告）号`、第8列 `公开（公告）日`、第9列 `申请号`、第10列 `申请日`、第12列 `专利类型`、第17列 `首项权利要求`、第19列 `独立权利要求`、第32列 `IPC`、第45列 `CPC`、第84列 `发明人`、第147列 `专利有效性`、第148列 `当前法律状态`、第149列 `法律状态`。
2. **知识库文本层**：来自第2列 `标题 (中文)`、第4列 `摘要 (中文)`、第17列 `首项权利要求`、第19列 `独立权利要求`、第215列 `DWPI标题`、第218列 `DWPI新颖性`、第219列 `DWPI详细描述`。
3. **画像标签层**：来自第25-30列技术功效字段、第31列 `用途`、第49-57列产业/学科分类字段、第216列 `DWPI用途`、第217列 `DWPI优势`、第224列 `DWPI手工代码`。
4. **推荐评估层**：来自第110列 `引证次数`、第111列 `被引证次数`、第132-135列同族数量和地区字段、第147-149列法律状态字段、第206列 `合享价值度`、第207列 `技术稳定性`、第208列 `技术先进性`、第209列 `保护范围`、第211列 `预估到期日`。
5. **增强分析层**：来自第98-117列引用关系字段、第125-140列同族和优先权字段、第146列 `一案双申`、第192列 `法律事件`、第193-196列公开/授权公告字段、第215-229列 DWPI 增强字段。
