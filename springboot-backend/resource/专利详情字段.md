# 专利详情字段
| 前端参数 | 字段名 | 从 Excel 哪些列提取 | 用途 |
|---|---|---|---|
| 专利号/公开号 | `patent_id` | `申请号` | 专利公开展示标识 |
| 专利标题 | `title` | `标题 (中文)` | 用户第一眼知道专利是什么 |
| 申请人 | `applicant` | `申请人`、`标准化申请人` | 判断专利申请主体 |
| 当前权利人 | `current_owner` | `当前权利人` | 判断当前专利归属 |
| 发明人 | `inventors` | `发明人`、`第一发明(设计)人` | 展示发明人信息 |
| 专利类型 | `patent_type` | `专利类型` | 区分发明、实用新型、外观设计等 |
| 法律状态 | `legal_status` | `当前法律状态` | 判断授权、公开、失效等状态 |
| 专利有效性 | `validity` | `专利有效性` | 判断专利当前是否有效 |
| 申请日 | `application_date` | `申请日` | 展示专利申请时间 |
| 公开日 | `publication_date` | `公开（公告）日`，可备用 `首次公开日` | 展示专利公开或公告时间 |
| 授权公告日 | `grant_date` | `授权公告日` | 展示授权时间 |
| 预估到期日 | `estimated_expiry_date` | `预估到期日` | 判断专利剩余保护期 |
| 技术摘要 | `abstract` | `摘要 (中文)` | 快速理解技术方案 |
| 技术功效句 | `technical_effect_sentences` | `技术功效句` | 展示较完整的技术效果描述 |
| 技术领域 | `tech_field` | `IPC` 对应的中文分类 + `新兴产业分类` + `知识密集型分类` + `学科分类` | 保存中文技术领域。`IPC` 列代码需要通过 IPC 中文映射表转换为中文；`新兴产业分类` 可能为空；`知识密集型分类` 和 `学科分类` 需要去除编号、代码等冗余内容，只保留中文名称 |
| 技术稳定性 | `technical_stability` | `技术稳定性` | 作为技术稳定程度评分 |
| 技术先进性 | `technical_advancement` | `技术先进性` | 作为技术先进程度评分 |
| 外部链接 | `source_link` | `链接到incoPat` | 跳转到 incoPat 查看原始详情 |
